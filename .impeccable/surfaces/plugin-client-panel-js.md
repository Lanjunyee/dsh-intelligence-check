# 原生检测工作页

## Scope

目标：plugin/client-panel.js 及生成的 plugin/client.js。Mode: Operate。主要用户任务：选择模型、选择题目、运行检测、阅读回答、预览与人工评审。保留全部功能、数据接口、提示词与检测规则。

## Direction contract

THESIS: 手动检测仍是默认入口，但检测操作收进底部紧凑操作区，回答成为居中的主要阅读面；四个页面入口与连接状态常驻顶部。

OWN-WORLD: 本机 Claude Desktop 4.16336.0 Code 界面的中性灰阶语言：宿主 sans 字体，纸张色页面、略抬升的输入区/面板、细边界、低对比次级文字与单一高对比主操作。浅色与深色都从宿主语义变量派生，不使用原“检测答卷”的绿色配置区与两栏工作区。按钮、菜单、字段、标签页、表格、浮层共享同一组 `--dic-*` tokens。

STORY: 打开质量题库，先看到居中的回答阅读区；在底部操作区用两个菜单选择模型与七道题目之一，运行后回答在上方展开，可切换历史记录、复制、下载、预览与人工评审；运行期间在底部取消。首次使用可从空状态或底部操作区前往添加检测目标。

FIRST VIEWPORT: 顶部为紧凑标题、连接状态、四个页面入口（质量题库/模型监测/模型指纹/检测记录）、刷新与设置；中部是最大约 760px 的居中回答列；底部是与 Code 输入区同形的操作区，包含检测模型、测试题、运行/取消，不提供自由文本聊天输入。题目菜单向上展开并在关闭后保留当前题目；运行按钮始终可见，不被长模型名挤掉。状态反馈以 160ms 过渡呈现，并尊重 reduced-motion。

FORM: 检测工作页，Code-first 改版。视觉权威是用户确认的本机 Code 实物参考（`.scratch/claude-desktop-redesign/screenshots/reference-code-{light-menu,light-settings,dark-main,dark-menu,dark-settings}.png`，本机 Claude Desktop 4.16336.0），不是早期方向轮的 worksheet 手牌或 seed；worksheet.html 与 seed:649c828e58e5be8e 仅作历史记录，不作为本轮验收依据。布局使用标准产品模式，代码优先，无批准的图像 comp。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Responsive and states

容器查询以 `.dic-page` 的 inline-size 为基准（不是视口），最终实现使用 860 / 740 / 560 / 480 / 420 五档；已实际验证 861/860、741/739、481/479 两侧，以及 1440px 桌面、390px 移动、1280×600 与 390×560 低高度。

- **≤860px：** 顶栏改为品牌/操作一行、页签一行并左对齐；检测记录从六列摘要切换为卡片摘要，时间为左上、结果与评审靠右、模型独占一行，行末保留 disclosure 箭头并显示“评审：”前缀。
- **≤740px：** 阅读列与操作区收窄内边距；评审字段、归因报告、回答对比、记录对比选择器改单列；历史筛选四列改两列，导出/清理等宽铺满；归因操作区单列，候选行改两列并把进度条移到名称下方；表格启用局部最小宽度 640px（候选）/720px（监测目标）。
- **≤560px：** 底部操作区的模型与题目菜单改单列，运行入口占满整行；监测页添加目标表单单列全宽；概览条改两列；设置行改单列。
- **≤480px：** 隐藏页签装饰图标，页签间距归零、左右内边距 7px、字号 12px，四个页面入口仍同屏可读。
- **≤420px：** 顶栏、阅读列、操作区内边距再收紧；操作区圆角 12px；回答工具栏占满整行；空状态降低最小高度；菜单浮层宽 320px。

回答滚动发生在中部的 760px 阅读区，底部操作区是 flex 布局中的一行、不覆盖正文/评审/浮层；题目菜单在短视口内自身滚动。回答空状态、运行中、失败、截断、无目标、长模型名与长正文均要可操作。

表格在窄屏下保持局部可读：模型监测目标表与模型归因“全部候选”表各自拥有横向滚动容器，640px 最小宽度只作用于这些容器内的表格；候选表展开后不得撑宽检测页面。浅色与深色主题都沿用宿主语义色。

代码排版：普通代码内容（原始提示词、预览代码）与代码回答（HTML、SVG、世界海陆地图题目的原始回答）统一使用宿主等宽字体、13px、1.7 行高；自然语言回答使用宿主 sans 字体、15px、1.75 行高。标签计数使用宿主等宽字体、11px。共享 tokens、顶部导航、按钮、字段与菜单样式供任务 02/03/04 复用。

状态与焦点：页签、按钮、菜单、开关与 disclosure 使用 160ms ease-out，`prefers-reduced-motion` 下全部取消；键盘焦点统一为 2px 主文字色轮廓、外扩 2px。错误为错误色横幅、截断为警告色、取消与无记录的空状态为中性提示，状态始终同时给出文字。
